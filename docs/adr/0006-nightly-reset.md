# 0006. Ночной сброс и «сегодня» всегда сегодня

**Статус:** принято

## Контекст

Если данные стенда сгенерировать один раз, через неделю «звонки сегодня» станут звонками недельной давности, а посетители оставят после себя проведённые документы и черновики.

## Решение

- `core/clock.py` — единое «сейчас» (в тестах замораживается).
- Фоновый цикл `sync.loop()` в процессе API раз в `SYNC_INTERVAL_S` проверяет, построена ли компания на сегодняшний день; если нет — `sync.reset()` пересоздаёт её от текущей даты, синхронизирует заново и очищает документы, черновики, трассы и чекпойнты LangGraph.
- В течение дня эмулятор «живёт»: звонки появляются по мере наступления их времени, дельта-синк подхватывает их.
- Таймер systemd в 03:00 МСК вызывает тот же сброс через `POST /api/admin/reset` — под той же блокировкой, что и фоновый цикл.
- Расход бюджета ИИ считается по календарным суткам и обнуляется сам.

## Последствия

- Утром стенд всегда показывает свежий день с теми же типами проблем.
- Действия одного посетителя не видны другим и не копятся.
