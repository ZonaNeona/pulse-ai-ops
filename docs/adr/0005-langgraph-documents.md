# 0005. Документы — граф LangGraph с остановкой на решении человека

**Статус:** принято

## Контекст

Ошибочная проводка в учёте дороже ручной проверки. Нужен конвейер, который проводит сам только бесспорные документы, останавливается на спорных и продолжает после решения человека — в вебе или в Telegram, сразу или через день, в том числе после перезапуска сервера.

## Решение

`modules/docs/graph.py`:

```
START → extract → validate ─┬─ все проверки прошли, уверенность высокая ─→ post → END
                            └─ что-то не так → review ── interrupt() ─┬─ провести → post → END
                                                                      └─ отклонить → reject → END
```

- `extract` — тип и реквизиты: правилами по тексту (PDF с текстовым слоем, TXT) или vision-моделью (фото, скан) через бюджет (0003).
- `validate` — проверки кодом по данным 1С, CRM и регламентам: контрагент и ИНН, заказ-основание, сумма в пределах 0,5 %, НДС, дубликат, неустойка по договору. У каждой проверки — ссылка на пункт регламента.
- `review` вызывает `interrupt()`: состояние сохраняется `AsyncSqliteSaver` в `var/langgraph.sqlite3` с `thread_id = doc-{id}`.
- Решение человека — `Command(resume=...)` в тот же поток; граф продолжает с места остановки.

Документы демо-очереди — обычный текст, построенный из данных дня, и проходят тот же граф, что и загруженный файл.

## Последствия

- Проверки детерминированы и объяснимы; модель только читает реквизиты.
- Граф рисуется на экране из самого кода (`draw_mermaid`), а не вручную.
- Ночной сброс очищает документы посетителей вместе с чекпойнтами.
