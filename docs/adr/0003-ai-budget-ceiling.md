# 0003. Суточный потолок расходов на модели

**Статус:** принято

## Контекст

Стенд открыт всем. Без ограничений один скрипт может потратить бюджет на модели за минуты.

## Решение

`core/budget.py` и единая точка вызова модели `core/llm.py`:

1. **Резерв.** Перед вызовом в одной транзакции (`BEGIN IMMEDIATE`) проверяются суточный потолок (`AI_DAILY_USD`, по умолчанию $1,5) и лимит посетителя (10 свободных вопросов и 3 документа в сутки), и бронируется оценка стоимости.
2. **Списание.** После ответа бронь заменяется реальной стоимостью из `usage.cost` OpenRouter. Ошибка провайдера — бронь снимается и в лимит не засчитывается. Если провайдер не вернул стоимость, остаётся оценка — потолок не занижается.
3. **Кто посетитель — решает сервер.** Лимиты считаются по хешу IP с солью процесса, а не по заголовку или cookie, которые легко подменить.
4. **Без модели — не ошибка.** Готовые ответы, регламенты (выдержки) и документы (правила) работают и без бюджета; ответ прямо говорит, почему модель не использовалась.

Расход за сутки и по часам — `GET /api/budget` и экран «Под капотом».

## Последствия

- Потолок соблюдается и при параллельных запросах.
- Расходы видны посетителю, стоимость каждого хода — в его трассе.
