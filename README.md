# Пульс — ИИ-платформа для операционной работы компании

Открытый демо-стенд: CRM, 1С, входящие документы и регламенты вымышленной компании «Норд Инжиниринг» (поставка и монтаж инженерного оборудования) — и ИИ-слой поверх них. Данные генерируются заново каждую ночь, «сегодня» на стенде всегда сегодня.

**Стенд:** https://demo.shvarev-demo.ru · **Как ведётся проект:** раздел «Как мы работаем» на стенде

## Что можно потрогать за две минуты

| Модуль | Что делает | Что внутри |
|---|---|---|
| **Продажи** | Пульс отдела к текущему часу, сигналы «сделать сейчас», команда с нормами, сделки, звонки с разбором по 8 критериям | Правила по данным CRM; разборы звонков сгенерированы вместе с демо-компанией |
| **Интеграции** | Статусы Битрикс24 и 1С, журнал синхронизаций, сверка «оплачено в CRM ↔ проведено в 1С» | Порты `CrmPort` / `ErpPort`; эмуляторы отвечают в формате REST Битрикс24 и OData 1С |
| **Документы** | Счета, УПД, акты, договоры проходят граф: реквизиты → сверка с 1С, CRM и регламентами → решение человека → проводка. Можно загрузить свой файл | LangGraph `StateGraph`, `interrupt()` на решении человека, чекпойнты в SQLite. PDF и TXT читаются правилами, фото — vision-моделью |
| **Знания** | Ответы по 10 регламентам со ссылками на пункт; вопрос вне регламентов — честный отказ | SQLite FTS5 по основам слов (snowball), BM25. Ссылки модели проверяются кодом, цитаты вырезаются из текста кодом |
| **Копилот** | Вопрос своими словами — ответ по данным, под ответом виден ход агента и его стоимость | Один реестр инструментов для встроенного цикла, Hermes Agent (через MCP) и Telegram-бота. Агент только читает; действия — черновики, которые подтверждает человек |
| **Под капотом** | Архитектура, бюджет ИИ за сутки, проигрывание последнего хода агента на анимированном холсте | Шаги трассы замеряются во время выполнения; стоимость — та, что вернул провайдер |
| **Как мы работаем** | Путь заказчика, дорожная карта разработки этого стенда, код и качество | Цифры качества снимает `tools/quality_report.py` при сборке релиза |

Частые вопросы копилота («какие сделки зависли», «сверка с 1С», «худший звонок», «документы на проверке») отвечаются сразу из инструментов, без модели и бесплатно. Свободные вопросы идут в модель с суточным потолком расходов **$1,5** на весь стенд и лимитом на посетителя.

## Как устроено

```
 Веб (React 19) · Telegram Mini App · Telegram-бот (aiogram 3)
                         │
                FastAPI · Python 3.12
 ┌────────────┬──────────┴───┬──────────────┬──────────────────────┐
 │  Продажи   │  Документы   │   Знания     │  Агенты              │
 │  сигналы   │  LangGraph   │  FTS5 + RAG  │  реестр инструментов │
 └─────┬──────┴──────┬───────┴──────┬───────┴──────┬───────────────┘
       │ CrmPort     │ ErpPort      │ core.llm     │ MCP-сервер ← Hermes Agent
       ▼             ▼              ▼              ▼
 Битрикс24      1С (OData)      OpenRouter     встроенный цикл, если Hermes недоступен
 эмулятор|live  эмулятор|live   (бюджет на каждый вызов)
```

- **Порты и адаптеры.** Модули не знают, эмулятор перед ними или живой портал: `CRM_MODE=live` + вебхук Битрикс24, `ERP_MODE=live` + OData 1С. Подключение только на чтение.
- **Посетители не мешают друг другу.** Сессия — HttpOnly-cookie, лимиты ИИ считаются по хешу IP. Документы, черновики и решения у каждого свои.
- **Бюджет ИИ.** Каждый вызов модели сначала резервирует сумму, затем списывает реальную стоимость из ответа OpenRouter. Нет ключа или бюджет исчерпан — работают ответы без модели, стенд об этом прямо пишет.

Решения с альтернативами и последствиями — в [docs/adr](docs/adr).

## Запуск локально

Нужны Python 3.12+ и Node.js 22+.

```bash
git clone https://github.com/ZonaNeona/pulse-ai-ops.git
cd pulse-ai-ops
cp .env.example .env            # без ключа модели всё, кроме свободных вопросов, работает

cd apps/api
python -m venv .venv && . .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
uvicorn pulse.main:app --port 8010
```

```bash
cd apps/web
npm ci
npm run dev                     # http://localhost:5180, API проксируется на :8010
```

При первом запуске API создаёт демо-компанию и синхронизирует её (около минуты). Swagger: http://localhost:8010/api/swagger.

Есть `docker-compose.yml` (API + собранный фронтенд за nginx): `docker compose up --build`.

### Свой Битрикс24 и 1С

```ini
CRM_MODE=live
B24_WEBHOOK_URL=https://your-company.bitrix24.ru/rest/1/<token>/

ERP_MODE=live
ONEC_ODATA_URL=https://1c.your-company.ru/base/odata/standard.odata/
ONEC_USER=...
ONEC_PASSWORD=...
```

### Модель и Hermes

```ini
LLM_API_KEY=...                 # любой OpenAI-совместимый провайдер, по умолчанию OpenRouter
AI_DAILY_USD=1.5
HERMES_API_URL=http://127.0.0.1:8663   # необязательно: без него отвечает встроенный цикл
HERMES_API_KEY=...
```

MCP-сервер для Hermes, Claude Desktop или IDE: `python -m pulse.agents.mcp_server` (stdio).

## Проверки

```bash
cd apps/api && ruff check . && ruff format --check . && mypy && pytest --cov=pulse
cd apps/web && npm run lint && npm run typecheck && npm test && npm run build
python tools/check_private_names.py
python tools/quality_report.py   # те же проверки + замер, который показывает стенд
```

CI на каждый коммит делает то же самое и дополнительно ищет секреты в истории (gitleaks).
